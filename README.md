# 架空鉄道ダイヤ工房

架空の鉄道路線を自由に作り、上下線の一日ダイヤを自動生成するオフライン Android アプリです。

## 主な機能

- 複数路線の新規作成・複製・削除
- 事業者名、路線名、路線記号、ラインカラー、方向名の編集
- 駅の追加・削除・並べ替え
- 駅間距離、停車秒数、快速停車駅の設定
- 始発、終発、運転間隔、表定速度から上下線ダイヤを生成
- 任意の列車種別、略称、色、運転頻度、停車駅を設定
- 上下方向ごとの基本行先と、列車ごとの行先・種別・直通有無を編集
- JR東日本の列車詳細を参考にした、発車時刻・番線・種別・行先・列車番号の案内表示
- 列車ごとの停車／通過、各停車駅の到着・発車時刻を自由に編集
- 列車ごとに中間駅を終点へ変更し、終点以後を運転なしとして時刻表へ反映
- 別路線を任意の分岐駅へ接続し、支線名、方向、頻度、接続停車、種別、行先を設定
- 支線列車の往復ダイヤと、列車ごとの本線・支線運転を編集
- 直通路線名、方面、頻度、接続停車時間、直通先種別、行先を生成画面で自由入力
- 朝・昼・夜・全日の時刻表表示
- 路線設定の JSON 書き出し・読み込み
- 生成時刻表の CSV 書き出し
- 端末内のローカルストレージへ自動保存

## 支線の設定

1. 「路線」で本線と支線に使う路線をそれぞれ作成します。
2. 本線を選び、「生成」→「支線運転」→「支線追加」を開きます。
3. 分岐駅、支線に使う路線、上下方向、運転頻度、接続停車、列車種別、行先を設定します。
4. 生成後は列車番号をタップして、その列車だけ本線運転または支線運転へ変更できます。

## 直通の設定

「生成」→「他路線への直通運転」で上り・下りを個別に有効化し、直通路線名、方面、種別、行先を直接入力します。直通先を「路線」画面へ登録する必要はありません。

## 列車詳細と停車駅時刻の編集

「時刻表」で列車をタップすると、発車時刻、発車番線、種別、行先、運転終点、支線・直通運転を列車ごとに変更できます。「この列車の終点」で中間駅を選ぶと、その駅が終点となり、以後の駅は時刻表で「—」（運転なし）になります。「停車駅情報」では、各駅の停車／通過と到着・発車時刻を編集できます。各駅時刻の変更欄を空欄にすると自動計算を使い、「全項目を自動へ戻す」でその列車の個別設定をまとめて解除できます。

## APK のビルド

このプロジェクトは Android SDK や Gradle に依存しない小型ビルダーを同梱しています。Python 3 と OpenSSL が必要です。

```sh
python3 tools/build_apk.py
```

出力先は `dist/KakuuRailwayDiaLab.apk` です。初回ビルド時に自己署名証明書を `build/signing` に生成し、Android 6 向けの V1 署名と Android 7 以降向けの V2 署名を両方追加します。同じ端末へ更新版を上書きする場合は、その署名ファイルを保管して再利用してください。

## 動作条件

- Android 6.0 以降
- インターネット接続不要
- 通信権限なし

## 構成

- `app/src/main/assets/` — WebView で動くアプリ本体
- `app/src/main/AndroidManifest.xml` — 可読用マニフェスト
- `tools/build_apk.py` — バイナリ Manifest、DEX、署名済み APK の生成
